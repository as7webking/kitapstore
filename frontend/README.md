# Frontend Kitapstore

Настройка и ограничения описаны в [основном README](../README.md).

Из этой папки: `npm ci`, настройте `.env` по `.env.example`, затем `npm run dev`.
Адрес API задаётся через `VITE_API_URL`. Проверки: `npm run build` и `npm run lint`.
Секреты и строка MongoDB во frontend не хранятся.
